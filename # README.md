# 📊 Personal Finance & Stock Portfolio App

A Streamlit dashboard to track expenses and visualize stock trends with simple AI-style signals.

## Features
- 💰 Expense Tracker with date picker, category chart, clear & download options
- 📈 Stock Portfolio viewer with:
  - 3-month price history
  - Configurable short & long EMAs
  - AI-style BUY/SELL/HOLD recommendations based on EMA crossover
- 📉 Trend visualization using Altair charts
